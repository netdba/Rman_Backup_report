  • Data Size Change: Negative values indicate the current backup's data size (Data Transferred) is smaller than the previous completed backup, which is expected for incremental backups (DB INCR) as they only back up changed data. For example, -20.39% means the current backup is 20.39% smaller than the previous one.
  • Unique Instances: If the number of unique instances is less than total instances, the TNS aliases in /home/oracle/dbscript/credentials.txt likely point to the same database instance. Verify /home/oracle/dbscript/credentials.txt and tnsnames.ora (typically in $ORACLE_HOME/network/admin) to ensure distinct SERVICE_NAME or SID for each instance.
  • Data Transferred and Media Space: Reflect total input and output bytes across all jobs in the last 7 days.
  • Success Rate: Percentage of completed jobs out of total jobs. Low rates may indicate systemic issues.
  • Average Throughput: Calculated as total data transferred divided by total jobs, indicating backup efficiency.
  • Log File: See /home/oracle/dbscript/dg_bkp_rpt/backup_report_20260930_0300.log for detailed execution logs and errors.
